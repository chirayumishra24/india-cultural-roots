# The Culture Quest: India's Cultural Roots
## Grade 6 Social Science Digital Learning Activity

**Chapter 7:** India's Cultural Roots  
**Theme C:** Our Cultural Heritage and Knowledge Traditions  
**Mode:** Classroom Summative Assessment & Collaborative Learning  
**Project Location:** `E:\skillizee\India-Cultural-roots`

---

### Key Features

1. **Faithful Visual Design**: Polished 2.5D game board aesthetic inspired by classroom game shows:
   - Wooden embossed header plaques ("THE CULTURE QUEST: India's Cultural Roots")
   - Central stylized Banyan / Peepal **Cultural Roots Tree** with visible organic roots, textured trunk, and glowing category nodes
   - 6 floating **Heritage Discovery Cards** with hand-crafted SVG illustrations (Manuscript, Music, Textile, Architecture, Storytelling, Craft)
   - Dual-team scoreboards (Team A: Root Seekers [Blue], Team B: Culture Keepers [Orange])
   - Cheerful animated student mascot duo with speech bubble
   - Cultural Tree Progress tracker with leaf gauges
   - Bottom interactive challenge console dock with clue preview, category badge, timer, and hint dropdown

2. **8 Challenge Categories**:
   - **KNOW IT**: Two-team quiz round with steal mechanic (+10 pts correct, +5 pts steal)
   - **FIND IT**: Culture Detective evidence examination and interpretation
   - **ROOT IT**: Signature activity connecting artifacts to their foundational cultural roots
   - **CONNECT IT**: Card relationship builder (e.g., Oral Folk Tale ↔ Spoken Language)
   - **BUILD IT**: Chronological & process stage ordering (Oral Recitation → Rock Edicts → Palm-Leaf Folios → Digital Access)
   - **SHOW IT**: Culture in Action (Act / Draw / Describe prompt + 2nd-step pedagogical reflection)
   - **THINK IT**: Critical inquiry exploring continuity and change without trick questions
   - **BLITZ**: Fast-paced 30-second rapid classification sprint

3. **Data-Driven & Culturally Sensitive Content**:
   - Strictly decoupled data files (`src/data/`)
   - Avoids single-origin oversimplifications or speculative claims
   - Fully customizable with verified textbook content

4. **Web Audio Sound Synthesizer**:
   - Procedural Web Audio API sound generator (clicks, chimes, swooshes, tree growth harmonics, victory fanfares) with zero external audio assets.

5. **Teacher Control Panel**:
   - Easily accessible anytime via gear icon or header click: rename teams, toggle timer, mute sound, skip clues, pause, restart round, or reset game.
